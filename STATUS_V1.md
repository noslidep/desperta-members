# Status real da V1

## Implementado no código
- Estrutura Next.js 16 App Router
- Login Supabase por e-mail/senha
- Proteção de rotas via Proxy
- Sessão SSR em cookies
- Schema PostgreSQL e RLS
- Dashboard e navegação da aluna
- Consulta de matrículas, programas, módulos e aulas
- Marcação de aula concluída
- Agenda, materiais e certificados
- Painel admin inicial
- Convite de aluna via Supabase Admin API
- Modo demonstração sem backend

## Interface pronta, operação administrativa ainda a completar
- Botões de criar/editar programa, módulo, aula e material
- Edição de perfil da aluna
- Abertura real de tickets de suporte
- Adicionar evento ao calendário
- Emissão automática do PDF do certificado

## Deliberadamente fora da V1
- Migração automática da TechFlix
- Integração com checkout/pagamento
- Streaming próprio de vídeo
- Tracking de segundos assistidos
- Analytics avançado

A V1 é a fundação funcional para iniciar homologação sem depender da TechFlix. As funções acima serão adicionadas por etapas para evitar construir e migrar tudo de uma vez sem validação.
