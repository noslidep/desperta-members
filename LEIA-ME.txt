- Aula 02 publicada com YouTube

FLUXO DE PUBLICAÇÃO
1. Subir este pacote em uma branch nova criada a partir de principal.
2. Executar supabase/migrations/20260925_v1_13_sala_de_comando.sql no SQL Editor do Supabase.
3. Abrir Administração > Conteúdos & Acessos > Sala de Comando.
4. Conferir 3 módulos e 12 aulas.
5. Alterar somente o curso para Publicado quando for iniciar o teste com uma aluna.
6. Manter Exibir capa na vitrine desmarcado durante o teste.
7. Liberar acesso individual para a conta de teste.

LIBERAÇÃO SEMANAL
As aulas futuras já existem no admin como rascunho. Quando chegar uma nova semana, basta inserir o link do YouTube e mudar a aula correspondente para Publicado. Para Mês 02 e Mês 03, publicar também o módulo quando chegar a primeira aula daquele mês.

Não há alteração em código da plataforma nesta versão.
